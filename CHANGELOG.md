# Changelog

## [0.1.0] — 2026-08-17

### Added

- Initial multimodal misinformation detection project delivery package.
- FastAPI backend with prediction, feedback, history, analytics, and health APIs.
- Text and vision model components with fusion architecture.
- Explainability and evidence services.
- React + TypeScript frontend.
- Browser extension prototype.
- PostgreSQL and Redis integration.
- Docker and Docker Compose deployment configuration.
- Automated backend tests.
- Professional project documentation and handover artifacts.

### Delivery Notes

This release is an MVP/academic-industry delivery baseline. Production deployment requires environment-specific secrets, infrastructure configuration, model validation, monitoring, and security hardening.
